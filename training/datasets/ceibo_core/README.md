# ceibo_core Dataset

Formato JSONL:

```json
{
  "instruction": "",
  "input": "",
  "response": "",
  "tags": [],
  "source": "",
  "rating": 0,
  "metadata": {
    "vertical": "",
    "risk_level": "",
    "language": "es-AR",
    "version": "v0.1"
  }
}
```

Reglas: no datos personales reales, no expedientes no anonimizados, no claves,
no informacion confidencial y no contenido peligroso operativo.
